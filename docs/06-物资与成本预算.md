## 核心部件选型

### 目标

在满足赛事规则与预算的前提下，确定两车的核心部件。

### 方案对比（为什么这样选）

| 部件 | 候选 | 结论与理由 |
|---|---|---|
| 主控 | STM32F103C8T6 / 其他 | STM32F103C8T6：官方物资表内、资料多、PWM 与定时器资源够 |
| 驱动 | DRV8833 / L298N | DRV8833：体积小、效率高、官方表内 |
| 遥控 | 官方 PS2 手柄 / 自购 | 官方 PS2：手册指定款、可对频锁定，全队只用一种通讯方式 |
| 舵机 | MG995（举升）/ SG90（翻盖） | 官方表内，扭矩/体积匹配 |
| 电池 | 18650（自行选型） | 手册指定 18650，2S 7.4 V 为上限 |

### 开发历程（从早到晚）

**2026-09-28 选型基线**：两车核心部件均取自《CRTC 官方物资表》，除 2 号车的灰度/红外传感器（新生组允许表外物资）。
