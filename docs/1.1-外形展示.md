# 1.1 外形展示

- **考核要求**：至少有一台具有能量单元的完整机器人机体，需绕车一周展示。
- **当前状态**：两车实物尚未拼装完成（3D 打印整批错印、PCB 首版接口问题），中期以 3D 建模概念图与 Fusion 装配流程代替实物展示。

## 我们的实现

两车按「抢价值 + 刷数量」分工：1 号车为麦轮取块车（举升立柱 + 换头机械臂），2 号车为四轮差速收运车（风车摇柄刺钩 + 一体斜铲唇 + 无隔板托盘）。两车均 PS2 手动操作。当前口径与桌面「一号车-最终版」「二号车-最终版」及《CRTC2026-双车最终方案报告-2026-10-12》一致。

| 项目      | 1 号车（过桥版）                                             | 2 号车（隧道版）                                      |
| ------- | ----------------------------------------------------- | ---------------------------------------------- |
| 定位      | 抢高分道具（物资架黄块 + 中央高台）                                   | 刷数量（地面与台阶散块 + 洞穴黄块）                            |
| 尺寸      | **208 × 140 × 207 mm**（限 290×195×210，高余 3）            | **收车位 288 × 186 × 129 mm**（长余 2、宽余 9、桥下净高余 1）  |
| 重量（预计）  | ≈1.2 kg（含车尾配重约 1.35~1.45；限 2.0）                       | ≈0.94~1.10 kg（限 2.0）                           |
| 行走与轮系   | φ60 麦轮 ×4 + TT 1:48                                   | φ70 橡胶轮 ×4 + TT（四轮差速；底盘离地 58）                  |
| 取块方式    | 快换接口（背板 18×48×24 + 公板 10×16×6）＋三种头：平行夹爪 / 钩子插头 / 弹片内撑 | 一体斜铲唇（纯坡面收地面块）→ 无隔板托盘；取块头＝松树针头 + 风车摇柄（MG90S×1） |
| 升降 / 动作 | C 口立柱 + 抱柱滑座；T8×150 丝杆 + 2×φ6 光轴；行程 46→172（126 mm）    | 连杆腕折 90°（推杆 + 30° 挡块 + 复位簧，关节 0 根电线）；铲唇抬起 35°  |

| 电控与电池   | 后区叠放：电池仓 75×42×22（下）+ 电控托盘 68×44×16（上，铜柱 28）          | 电控/电池高架 160×70（电池靠尾、PCB 在前）                    |

## 方案与取舍

两车形制按 A + B 设计：1 号车抢中央高台与杆上高分方块，2 号车抢地面保分方块并尝试掏出洞穴高分方块。

- **1 号车**：伪机械臂方案。除底盘运动外，设置 3（或 2）个电动自由度——手臂沿立柱升降、手臂绕立柱接触点转动、夹爪开合；另有 2 个手动自由度（见 2.1 进阶功能）。受尺寸与战术限制，料仓不大，置于车前。
- **2 号车**：铲唇 + 倒刺勾取。方块仓吊挂在车体下方，尺寸经核对可容纳目标方块；地面块由铲唇 + 舵机翻转流程拾取，洞穴块由松树状倒刺（舵机做圆环覆盖）引导出来，再由铲唇接收。
- **底板**：现成定版底座无法满足尺寸与战术需求，团队改用 3D 打印构建主体结构。

## 难点与解决

- **3D 打印整批错印**：10-14 提交打印件，整批错印、缺主体件，导致无法拼装；中期只能以 3D 建模概念图与 Fusion 构建/装配流程代为展示（重打进度待补）。
- **PCB 首版接口问题**：首版 PCB 考虑不周，接口出错，需进一步调试；中期无法展示终版，只展示该错误布线版本。
- **面包板接触不良**：万用表蜂鸣检测时高频出现板内断联，在电机测试中排查很久；最终舍弃面包板，改为母头直插引脚 + 焊接（详见 1.2）。
