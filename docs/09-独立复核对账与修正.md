## 一、三处高优先级硬伤 —— 全部采纳

### 1. 2 号车初始长向尺寸会超 290（检录硬线）

- 手册原文（3.3 设计技术规范）："机器人的初始长宽尺寸不得超过 290mm×195mm，高度不得超过 210mm"；"注：初始尺寸指**每次对局正式开始时**机器人的尺寸。"
- 我们的真实账：**车体 280 + 铲唇前突** → 固定唇 ≈380 ✗；按"被动回缩"设计，**弹簧静止时把唇板推出来**，初始态仍是 ≈380 ✗ → 检录直接不过。
- **修正（定稿）**：铲唇改为 **SG90 主动推拉**：
  - 初始态：唇板全收，前突 0–5 → 总长 **280–285 ✓**；
  - 地面收块：一键伸出（与之前一致）；
  - 洞穴/矮墙作业前：收回（贴墙作业）。
  - 副作用：2 号车 +1 个 SG90（≈ +10 g）；断电时由弹簧把唇板拉回"收起"位保底。
- 备选：车体缩到 **270**（低仓 2×6 仍放得下，富余 44mm）——排期紧张就用这个。
- 对复核算据的修正：复核按"托盘 204 + 前后轮 60+60"推出"车长 ≥324"，**重复计了一次**（轮子在 280 车体内、托盘放在前后轴之间），车身 280 本身没问题；真正超限的是**铲唇前突**。

### 2. 1 号车 e3 物资架黄块"伸不进 0.5mm 缝"

- 复核正确：方块 30、内腔 15，挂杆 φ14 → 中缝 0.5mm，弹片/倒刺都进不去。
- **修正**：e3/d6 末端改为 **"外缘拉钩"**（从方块侧面钩外缘、沿杆轴拉出，纯被动），备选 **SG90 小夹爪夹外表面**。
- 验证：打印 30 方块 + φ14×150 杆 + 拉钩，20 次 ≥18/20 通过。
- 文档同步：把"单向倒刺沿轴抽出"的表述改为"外缘拉钩（首选）/ 夹外表面（备用）"。

### 3. "半自动 ≈32.5"不能当计划值

- 复核正确：PS2 手动 + 一键宏，按手册字面属"一般机器人"（白 ×1、黄 ×4）。
- **修正**：对外文档统一写 **27 分为计划值**、"32.5 为待答疑的潜在上限"；运行模式三选一只写一种，不混写。
