# 开源项目使用说明

> 依据《2026 CRTC 参赛手册》V1.5：将开源项目用于机器人的制作及代码编写是允许的，但**必须在中期考核阶段给出完整说明**，并遵守所使用开源项目的开源协议；文档规范（4.3.1）要求在**文档末尾完整说明**。
> 填写分工：**电控组（李秉航）**确认版本与许可证；队长汇总。中期考核前必须填完。

## 三、合规声明

- 上述开源项目的许可证条款均予以遵守；如对源码有修改，将在本页注明修改内容与范围，并遵守对应许可证（如保留版权声明、开源衍生代码等）。
