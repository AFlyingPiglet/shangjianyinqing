# 1.11 结构稳定性

- **考核要求**：180 mm 自由落体不掉件。
- **当前状态**：设计措施已落实，落体测试待做。

## 我们的实现

- 电池仓、料仓（堆块筒）、电控托盘均有绑扎或压紧位；电池仓与托盘在后区叠放并以 M3 铜柱/M3 螺丝固定。
- 两侧孔列板 + 对穿 M4×80 插销可作横撑/挂点/锁结构；走线全部走底盘内或贴边，车顶不翘线。
- 打印件备件已列：松树针头 / 腕部摇臂 / 挡块座各多打一件。

## 方案与取舍

- 以「150~200 mm 跌落不脱件」为验收标准；关键件用 PETG（受力件 40% 填充），外壳件 PLA。
- 孔列板不仅加固，还兼作对穿绑定位（电池、顶盖、传感器）。
