# 1.2 电机运动（单一）

- **考核要求**：能完成至少一个电机的转动。
- **当前状态**：✅ 已调通（调试证明可行，待补视频）。

## 我们的实现

TT 1:48 马达 + DRV8833 驱动模块，主控输出 PWM 调速；电机经驱动模块由主控控制，可按既定代码转动。测试程序（F401 最小版）：TIM3 输出 20 kHz PWM（PA6/PA7 → DRV8833 AIN1/AIN2），循环「正转 2 s → 停 1 s → 反转 2 s → 停 1 s」。

## 方案与取舍

- 电机：官方物资表内的 TT 1:48，价格低、扭矩够、驱动简单；驱动器选 DRV8833（1 号车 ×2、2 号车 ×4，共 6 块）。
- 关键取舍：**驱动模块必须焊接**——实测驱动两侧无电压，说明仅插接/面包板不可靠；焊接后电机正常转动。
- 面包板舍弃：万用表蜂鸣检测时高频出现板内断联（在电机测试中排查很久），改为母头直插引脚 / 焊接直连。

## 难点与解决

- **现象**：通电单独测试时马达、电池均正常，但电机驱动两侧无电压。
- **排查**：从前一天测得 GND 与 VM 之间仅 0.12 V 入手，确认驱动供电/焊接问题 → 重新焊接驱动并补购驱动模块。
- **二次现象**：焊完用跳线让电机转起来，但「转两秒、停两秒」循环测试始终不通过；判断为面包板与公头接触不良 → 手动接入、直连引脚恢复通路。

## 开发历程（精简）

- 2026-09-28：确定 TT 1:48 + DRV8833 方案。
- 2026-10-13：马达输出检验——驱动两侧无电压（GND–VM 仅 0.12 V）→ 焊接并补购驱动。
- 2026-10-14：焊后电机首次转动成功；循环测试受面包板接触不良影响，改直连解决。
