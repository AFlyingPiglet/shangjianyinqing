# 1.5 舵机运动（多项）

- **考核要求**：不少于 3 个舵机，且可动机构能在任意非初始状态保持静止。
- **当前状态**：未实现——硬件具备（1 号车 3 舵机），同时控制未实现。

## 我们的实现

1 号车：肩 MG995、肘 MG995、夹爪 MG90S，共 3 舵机；2 号车 1 颗 MG90S（唇板 SG90 选配）。断电保持：举升靠 T8 梯形丝杆自锁，臂关节靠机械限位/销钉。

## 方案与取舍

- 用 3 舵机覆盖「举升 + 摆臂 + 夹取」三个动作，不再增加第四颗舵机（降低重量与布线复杂度）。
- 需要「任意非初始状态保持静止」：肩/肘用大扭矩 MG995 + 铜套铰链（φ5×φ8×8），举升丝杆自锁，断电不掉臂。

## 难点与解决

- 现状：多舵机同时控制未实现，与 1.3 的接收/手柄配对与烧录异常相关（同一套代码灯态异常、无法稳定写入）。
- 后续：先解决通信问题，再做 3 舵机联动与断电保持演示。
