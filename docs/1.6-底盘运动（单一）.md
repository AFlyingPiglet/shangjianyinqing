# 1.6 底盘运动（单一）

- **考核要求**：能用 PS2 手柄控制至少一个底盘的水平运动（车体与手柄同框或给出代码）。
- **当前状态**：未实现（手柄配对成功，控车行进未通；原因见 1.3）。

## 我们的实现

1 号车：官方 PS2 无线手柄 + 麦轮全向底盘（φ60 麦轮 ×4、TT 1:48），设计限速约 0.5 m/s，兼顾过桥与对位精度。

## 方案与取舍

- 官方 PS2 手柄（物资表内）+ 麦轮：可横移/斜行，贴窄槽与高台对位最省事；坡上辊子会侧滑，用导向片 + 限速守住。
- 通信问题见 1.3（配对/烧录异常），底盘运动同样受影响。

## 难点与解决

- 2026-10-15 配置手柄：绿灯常亮、红灯一直闪烁配对不上 → 检查引脚、交叉验证、替换部分导线后完成配对；但未能实现用手柄控制车体行进。
