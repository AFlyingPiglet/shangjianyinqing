## 写作要求（务必遵守）

1. **格式**：markdown（.md）。
2. **以单个机器人的一个具体功能为一个板块**：`## 功能名称` 作标题，正文写「功能描述 + 开发历程」。基础功能直接按考核指标逐项组织。
3. **按时间从早到晚**组织内容（开发历程从最早的方案讲起，写到当前状态）。
4. **必须写「为什么」**：技术选型对比、遇到的难点与解决方案、迭代优化的过程。只写「做了什么」拿不到高分。
5. 图片放在 `docs/images/`，用相对路径引用：`![](images/xxx.png)`。
6. 每次有进展就提交一次，不要攒到最后一天。
