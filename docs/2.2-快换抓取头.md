# 2.2 快换抓取头

- **关联基础功能**：1.9 方块携带（单一）
- **一句话**：1 号车抓取头可快速更换，用纯机械头实现被动抓取，避免带电结构。
- **当前状态**：结构方案完成（统一背板 + 三种头）；实物未组装，换头演示待补。

## 方案与取舍

- 统一接口：每个头 = 18×48×24 背板 + 10×16×6 公板；背板 2×M3@±16（孔距 32）+ φ5.05 定位销，与腕板母板同孔位，换头约 10 秒。
- 三种头：平行夹爪（默认，张开 38~40 / 合拢 28~29）、钩子插头（物资架）、弹片内撑（被动）。
- 用被动头替代「带电的第二套夹爪」：断电不掉块、少舵机、少走线。

## 难点与解决

- 早期腕板 32 宽的公板接口与各头不统一 → 统一背板尺寸与孔距解决。
